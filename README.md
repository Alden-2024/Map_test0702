# 3D地图展示应用

这是一个基于高德地图JS API v2.0开发的3D地图展示应用，具有以下功能：

- 3D地图视图与立体拖动交互
- 3D建筑物图层显示
- 南京区域矩形高亮显示
- 地图点击烟花爆炸效果
- 响应式设计，适配移动端

## 使用方法

1. 克隆本仓库到本地
2. 替换`map.html`中的`您的高德API密钥`为您自己的高德地图API密钥
3. 打开`map.html`文件即可运行应用
